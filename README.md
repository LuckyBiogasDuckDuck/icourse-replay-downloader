# iCourse 回放下载器

把**复旦大学智慧教学资源平台**（`icourse.fudan.edu.cn`）的课堂回放另存到本地。
Chrome / Edge 扩展，装完即用。

支持**下载当前这一节**，也支持**按页面上的章节清单批量下载整门课**。

---

## 先说清楚：它做什么、不做什么

**做：**
- 把当前这节课的录像另存为本地文件
- 批量下载：逐节点击章节行 → 等这一节加载出来 → 下载 → 再切下一节
- 下载交给**浏览器自带的下载器**，所以能暂停、能续传、进度在 `chrome://downloads` 也能看

**不做**（刻意不做的）：
- 不伪造观看进度、不改播放记录、不向平台伪造心跳
- 不绕过任何鉴权
- **不处理加密内容**：遇到加密流直接放弃并告诉你原因

一句话：只把**你能正常播放**的内容另存一份。

## 一、安装（约 1 分钟）

1. 打开 Chrome 或 Edge，地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角的 **开发者模式**（Developer mode）。
3. 点 **加载已解压的扩展程序**（Load unpacked）。
4. 选择本仓库的**文件夹本身**（就是含 `manifest.json` 的这一层）。
5. 建议点一下浏览器工具栏的拼图图标，把「iCourse 回放下载器」**固定**到工具栏。

---

## 二、怎么用

1. 正常登录 `icourse.fudan.edu.cn`，打开一节课程视频。
2. 视频右上角会出现一个深色小面板。**按住标题栏可以拖动**，点 `–` 收起，点 `×` 隐藏
   （隐藏后点工具栏图标能再叫出来）。
3. 看面板上「本节媒体地址」那一栏：
   - 显示 `https://....mp4` 并且标着**直连** → 点 **「下载本节」**，收工。
   - 显示 `—` 并提示 `blob:` → 见下面「下载不了的时候」。

### 批量下载整门课

1. 在页面上把**课程目录展开**（要让章节行出现在页面里）；
2. 点 **「扫描章节」** —— 面板会列出扫到的所有章节，当前播放的那一节会高亮；
3. 点 **「开始批量」**。

批量下载会**逐节停留若干秒**，因为要点进每一节等它加载。等待时长在面板上可以调
（**每节加载等待**，默认 12 秒）：网络慢就调大，调太小会把还没加载出来的节误判成失败。

> 为什么要等上一次下载完才切下一节？因为切节会让播放器重新加载，可能打断正在进行的下载。

---

## 三、下载不了的时候

先点 **「复制诊断信息」**，把复制到的内容发给帮你排查的人（或者开个 issue）。里面包含媒体地址、视频的真实地址、章节清单等。

三种常见情况：

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 面板显示 **blob:** | 这个播放器用 MSE 边下边播，`<video>` 上拿不到真实文件地址 | 把诊断发我，看能不能从网络请求里找 `.m3u8` / `.mp4` 接上 |
| 提示 **加密流，不处理** | 这节是加密的 HLS | 本插件不做解密，也不会去做 |
| 批量下载里**个别节失败** | 多半是「每节加载等待」太短 | 调大等待秒数再试 |

## 四、技术说明（想改代码再看）

### 支持两种媒体形式

| 形式 | 面板徽标 | 处理方式 |
|---|---|---|
| 直连文件（`.mp4` 等） | **直连** | 地址直接交给浏览器下载器。可暂停/续传，最稳 |
| HLS（`.m3u8`） | **HLS · 抓流合并** | 插件自己拉播放列表、自动挑最高码率、逐片下载、拼成一个文件再交给下载器 |

HLS 走的是插件自己的 `fetch`，**会在内存里拼完整个文件** —— 超长的课留意内存。

### 文件结构

```
icourse-replay-downloader/
├── manifest.json              MV3 清单
├── src/
│   ├── background.js          Service Worker：调用 chrome.downloads、回报进度、右键菜单
│   ├── shared/
│   │   └── downloads.js       纯函数：文件名清洗、m3u8 解析与选流、体积格式化
│   └── content/
│       ├── content.js         视频/章节探测、面板 UI、批量下载流程
│       └── panel.css          面板样式（想改外观改这个文件）
└── test/
    ├── downloads.test.js      纯函数单测（78 项，不需要浏览器）
    ├── serve.js               本地 fixture 服务器
    ├── make-test-build.js     生成用于测试的扩展副本
    ├── e2e.ps1                端到端测试（真实浏览器加载扩展）
    └── fixture/index.html     模拟课程页（按真实站点结构复刻）
```

### 两个实现上的坑（都已处理，写在这里免得重踩）

1. **`chrome.downloads` 在内容脚本里不可用**，只有 background 有。所以下载动作走消息转发。
2. **内容脚本 `fetch` 扩展内文件需要 `web_accessible_resources` 声明**。
   少了它，`panel.css` 会读不到，面板就变成一堆没样式的原生 HTML —— 而且不报错。
   e2e 里有一条断言专门守这个。

## 五、跑测试

```powershell
# 纯函数单测，不需要浏览器
node test/downloads.test.js

# 端到端：真实浏览器加载扩展，打开本地模拟课程页
powershell -NoProfile -ExecutionPolicy Bypass -File test/e2e.ps1
```

端到端测试断言 10 件事：面板注入、视频探测、媒体地址识别、章节扫描与高亮、
**下载请求真的交给了浏览器下载器**、以及**面板样式真的生效**。

> 注意：`test/e2e.ps1` 必须保存为 **UTF-8 带 BOM**，否则 Windows PowerShell 5.1
> 会按 ANSI 解析中文而直接语法崩溃。

## 六、隐私

- 扩展**不上传任何数据**，没有自己的服务器。
- 不使用、不存储你的复旦账号密码，只沿用浏览器里已有的登录状态。
- 下载请求直接由浏览器发往课程站点，与手动点播时走的是同一套会话。
